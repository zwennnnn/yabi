# PROMPTS TR / EN

## TR

### Komple Site

```text
Use $yabi. Bana sadece landing değil, komple bir web sitesi tasarla ve inşa et.
Rota haritası, bilgi mimarisi, görsel dünya, motion fiziği, component sistemi,
homepage, kritik iç sayfalar, navigation, footer, CTA, form durumları,
responsive davranış ve final audit dahil olsun. Kart grid, generic ikon,
ucuz gradient ve sıradan hero kalıbı istemiyorum.
```

### Site Refactor

```text
Use $yabi. Bu mevcut siteyi içerik metinlerini bozmadan arşa çıkar. Önce
route/section yapısını ve AI kokusu taşıyan patternleri analiz et. Sonra aynı
bilgi akışını koruyarak görsel dünya, layout, motion, responsive ve
erişilebilirlik kalitesini yükselt.
```

### UI Test

```text
Use $yabi-ui-tester. Bu siteyi Playwright ile route ve viewport bazında tara.
Screenshot, console, network, kırık medya, axe-core, overflow, overlap ve YABI
yasaklı pattern raporu üret. Screenshot'ları gerçekten incelemeden karar verme.
```

## EN

### Complete Website

```text
Use $yabi. Design and build a complete website, not only a landing page. Include
route architecture, information architecture, visual world, motion physics,
component system, homepage, key inner pages, navigation, footer, CTAs, form
states, responsive behavior, and final audit. Avoid card grids, generic icons,
cheap gradients, and predictable hero templates.
```

### Site Refactor

```text
Use $yabi. Elevate this existing site without changing the preserved copy.
Analyze routes, sections, and generic AI UI patterns first. Then keep the same
information flow while upgrading visual world, layout, motion, responsive
behavior, and accessibility.
```

### UI Test

```text
Use $yabi-ui-tester. Audit this site with Playwright across routes and
viewports. Produce screenshots, console logs, network errors, broken-media
checks, axe-core results, overflow/overlap signals, and YABI banned-pattern
findings. Do not judge before inspecting screenshots.
```
