# YABI Prompt Paketi

## Komple Site Üretim Prompt'u

```text
Use $yabi. Bana sadece landing değil, komple bir web sitesi tasarla ve inşa et.
Önce rota haritasını, içerik omurgasını, görsel dünya premisini, motion
fiziğini ve component mimarisini çıkar. Sonra homepage, kritik iç sayfalar,
navigation, footer, CTA, form durumları, responsive davranış ve final audit ile
üret. Kart grid, generic icon, gradient ve sıradan hero kalıbı kullanma.
```

## Refactor Prompt'u

```text
Use $yabi. Bu mevcut siteyi içerik metinlerini bozmadan arşa çıkar. Önce
mevcut route/section yapısını analiz et, sonra hangi AI kokusu taşıyan pattern
varsa sök. Aynı bilgi akışını koruyarak görsel dünya, layout, motion,
responsive ve erişilebilirlik kalitesini yükselt. Finalde YABI audit rubriğiyle
bulguları kapat.
```

## Denetim Prompt'u

```text
Use $yabi and $yabi-ui-tester. Siteyi gerçek tarayıcıda test et, ekran
görüntülerini ve JSON raporlarını incele, kritik kırıkları düzeltme listesine
çevir. Özellikle okunabilirlik, responsive, route bütünlüğü, yasaklı pattern ve
motion jank arıyorum.
```

## Sektör Stres Testi Prompt'u

```text
Use $yabi. Aynı tasarım kuralını üç farklı sektör brief'inde test et: berber,
restoran ve danışmanlık. Kuralın hepsinde kaliteyi artırıp artırmadığını
değerlendir. Sadece tek sektörde işe yarıyorsa anayasa kuralı değil, sektör
notu olarak işaretle.
```
