# Visual World Building

## Premise

Do not start with abstract adjectives. "Premium", "modern", "minimal", and
"clean" are not decisions. Start with a concrete world:

```text
This site makes [brand] feel like [specific place, moment, ritual, or system]
inside the mind of [audience].
```

Examples:
- Barber: after-hours light sliding across stainless steel and mirrors.
- Restaurant: the warm pressure of a kitchen minutes before service.
- Consulting: a crisis room where decisions become visible maps.
- SaaS: a live operations center glowing in the dark.

## Light

Choose a light source:
- Hard side light: sharp, technical, luxurious, tense.
- Soft overhead light: calm, editorial, trustworthy.
- Screen light: SaaS, data, control, systems.
- Window light: craft, people, place, reality.

Light must obey the same physics across the site.

## Material

Pick one primary material language:
- Do not use glass if nothing is glass.
- Do not add metallic shine without metal.
- Do not add paper grain without a paper world.
- Do not use neon data lines without a digital system premise.

Material must touch the business.

## Color

Color comes from the user preference or the brief context, not random taste.
Every main color needs a reason:
- Warmth: people, food, craft, closeness.
- Coldness: technology, precision, distance, control.
- High contrast: claim, pressure, theatrical impact.
- Low saturation: maturity, silence, trust.

Gradients are not a default solution. Use them only when they emerge from real
light, photography, or material.

## Typography

Treat type as character:
- Display type opens scenes.
- Text type carries trust.
- Mono type appears only when systems, measurement, or technical rhythm matter.

Do not repeat the same sizes blindly across every route. Homepage can be more
theatrical; inner pages can be more readable. Same family, contextual behavior.

## Asset Strategy

Use real imagery or video. For each asset ask:
- Is the subject real or stock-like?
- Is there a safe text zone?
- Is it at least 1920px wide for hero use?
- Does its color and light match the world plan?
- Does the mobile crop still mean something?

When downloading assets, report source, file name, route/section, and reason.
