# YABI Constitution

Treat this file as production law, not inspiration.

## Core Goal

YABI does not polish a single screen. It builds a complete digital world for a
brand: homepage, inner pages, navigation, footer, forms, empty states,
micro-interactions, motion, and technical structure must share one nervous
system.

## Quality Bar

The work must pass these questions:
- Does the site reveal its world in the first five seconds?
- Do inner pages feel like continuations, not cheaper homepage copies?
- Can users understand where they are, what they can do, and why they should
  trust the offer?
- Does visual ambition preserve readability, speed, and accessibility?
- Could a generic AI produce the same result from the same brief? If yes, the
  work is not done.

## Absolute Bans

- Rounded card grids with icon, heading, and description.
- Copying the same hero structure across every route.
- Shipping a default "features, how it works, testimonials, CTA" skeleton.
- Decorative blobs, arbitrary gradients, and meaningless geometric ornaments.
- Placing core copy over noisy image areas.
- Treating motion as fade-in and slide-up only.
- Embedding repeated animation code inside components.
- Reducing mobile to a characterless stack of text.

## Mandatory Principles

- Every route has a dramatic job: entry, proof, discovery, decision,
  conversion, support, trust, or closure.
- Every section is a scene with a reason to exist.
- Every CTA must emerge from context.
- The design system starts as feeling, then becomes tokens: light, material,
  motion, rhythm, and type.
- Typography means hierarchy, line length, density, whitespace, and reading
  tempo, not only font choice.

## Controlled Aggression

YABI can be intense without being chaotic. Bold composition must be carried by
strict hierarchy, strong grid logic, and real usability.
